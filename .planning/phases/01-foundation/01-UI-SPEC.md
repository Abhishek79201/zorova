## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, inline badge padding |
| sm | 8px | Compact element internal padding, gap between stacked tags |
| md | 16px | Default card padding, form field spacing, body paragraph gap |
| lg | 24px | Card-to-card gap, nav link spacing, inline section padding |
| xl | 32px | Content column horizontal padding (mobile sections) |
| 2xl | 48px | Section vertical padding (mobile), major component gap |
| 3xl | 64px | Section vertical padding (desktop), hero internal padding |
| 4xl | 80px | Page-level top/bottom padding |

Exceptions:
- Touch targets for interactive controls (hamburger toggle, WhatsApp FAB, nav links): minimum 44px hit area per WCAG 2.5.5 — this overrides the spacing scale for `min-height`/`min-width` only, not visual spacing
- Navigation height: 64px (desktop), 56px (mobile) — matches brand proportion, not a standard token
- Skip-to-content link: positioned absolutely, no spacing token applies

Source: 8-point scale standard; legacy Vite SPA spacing tokens as cross-reference; A11Y touch target requirement from REQUIREMENTS.md A11Y-06.

## Typography

Four-size, two-weight system. All sizes in px; rem equivalents shown for implementation.

| Role | Family | Size (px) | Size (rem) | Weight | Line Height | Usage |
|------|--------|-----------|------------|--------|-------------|-------|
| Display | Playfair Display | 56px (mobile: 36px) | 3.5rem / 2.25rem | 700 | 1.2 | Page hero H1 |
| Heading | Playfair Display | 40px (mobile: 28px) | 2.5rem / 1.75rem | 700 | 1.25 | Section H2 |
| Subheading | Plus Jakarta Sans | 20px | 1.25rem | 700 | 1.3 | H3, card titles, nav links |
| Body | Plus Jakarta Sans | 16px | 1rem | 400 | 1.6 | Paragraphs, descriptions, form labels, timestamps, fine print, badge text |

Weights in use: **400** (regular) + **700** (bold). These are the only two declared weights. Playfair Display at 700 and Plus Jakarta Sans at 700 occupy a single declared weight slot (bold).

Button labels use Body role: Plus Jakarta Sans 16px weight 700.

Minimum body size: 16px — hard floor per REQUIREMENTS.md A11Y (WCAG AA, 16px minimum). Timestamps, legal fine print, and badge text are rendered at Body (16px) — the 14px Caption role is removed to satisfy this floor and the 4-size maximum.

Source: REQUIREMENTS.md DS-05 type scale spec, PROJECT.md constraints "16px body minimum", legacy Vite font pairing. Revised 2026-04-14 per checker: collapsed from 5 sizes/3 weights to 4 sizes/2 weights.

### Accent (`#8442f5`) Reserved For

Accent is applied **only** to these specific elements:

1. "Book Now" navigation CTA button (fill and border)
2. Active route indicator (underline on current nav link)
3. Focus-visible ring on all interactive elements (`outline-color`)
4. WhatsApp FAB icon background (combined with green where required by WhatsApp brand)
5. Gradient endpoint in hero/CTA banner (`#3e1b7c` → `#8442f5` direction)
6. "Most Popular" badge on PricingTier card
7. Hover state decoration on card bottom-border accent stripe

All other interactive elements (standard links, secondary buttons, form inputs) use `--color-primary` (`#3e1b7c`).

### Decorative-Only Color

`#b08eeb` (secondary) **must not appear as text**. Allowed uses only:
- Gradient midpoint in hero/CTA overlays (not standalone text)
- Decorative illustration fills
- Background of `<HighlightBox>` "Did You Know?" callouts (text inside must be `#09080a` or `#3e1b7c`)

WCAG contrast: 2.8:1 on white — fails AA for text.

### Semantic Color

| Role | Hex | Usage |
|------|-----|-------|
| Destructive | `#c0392b` | Destructive actions only — form delete, destructive confirm dialogs |
| Success | `#2d7a4f` | Form submission success inline message |
| Warning | `#d4a017` | "Coming Soon" badge fill |

Source: REQUIREMENTS.md DS-01, DS-02; legacy Vite SPA color tokens cross-reference; WCAG contrast math.

## Component Contracts

### Navigation (`src/components/navigation.tsx`)

- Height: 64px desktop / 56px mobile
- Background: `#ffffff` initially → `rgba(255,255,255,0.85)` with `backdrop-filter: blur(12px)` on scroll + `box-shadow: 0 1px 8px rgba(62,27,124,0.08)`
- Logo: left-aligned, links to `/`
- Nav links (desktop): 10 links center or right, 16px Plus Jakarta Sans weight 700, `#09080a` default, `#8442f5` underline on active route
- "Book Now" CTA: rightmost, accent button (`#8442f5` bg, white text, radius 8px, 16px font, weight 700)
- Mobile (≤768px): hamburger icon (Lucide `Menu`), 44px touch target, `aria-label="Open navigation menu"`, opens Sheet drawer with full link list + "Book Now" CTA
- Animation: frosted-glass transition on scroll uses `transition: background-color 200ms ease, box-shadow 200ms ease`
- Built as `"use client"` component — uses scroll listener and Sheet state

### Footer (`src/components/footer.tsx`)

- Background: `#3e1b7c` (primary deep violet)
- Text: `#ffffff` primary, `rgba(255,255,255,0.7)` secondary links
- Layout: 4 columns (desktop) → 2 columns (tablet) → 1 column (mobile), `gap-8` (32px)
  - Column 1: Zorova logo (white variant) + "Wellness for Every Home" tagline + social icon row
  - Column 2: Quick Links (6 navigation links)
  - Column 3: Legal (Privacy, Terms, Cancellation)
  - Column 4: Get in Touch (phone/email) + "App — Coming Soon" note
- Bottom bar: `border-top: 1px solid rgba(255,255,255,0.15)`, "© 2026 Zorova Wellness Pvt. Ltd. All rights reserved. | Made with care in India"
- Social icons: Lucide icons (Instagram, Facebook, LinkedIn, Twitter/X), 20px, white, 44px touch targets

### WhatsApp FAB (`src/components/whatsapp-fab.tsx`)

- Position: fixed bottom-right, `bottom: 24px right: 24px` (desktop), `bottom: 16px right: 16px` (mobile)
- Size: 56px diameter circle
- Background: `#25d366` (WhatsApp brand green) — exception to Zorova palette; brand requirement
- Icon: Lucide `MessageCircle` or custom WhatsApp SVG, white, 24px
- Shadow: `0 4px 16px rgba(37,211,102,0.4)` (green glow)
- Hover: `scale(1.08)` lift, shadow intensifies
- `aria-label="Chat on WhatsApp"`, links to `wa.me/91XXXXXXXXXX`

### Placeholder Route Pages (`src/app/*/page.tsx`)

- Content: centered `<main>` with page title in Display type (Playfair Display 56px weight 700) as the primary visual anchor + "Coming soon" subtitle in Body type (Plus Jakarta Sans 16px weight 400)
- Visual focal point: the H1 in Display type at 56px is the primary visual anchor on all skeleton pages — it must be the first and largest typographic element, centre-aligned, with `padding-top: 80px` from the navigation
- Background: alternating per route (home=white, massages=bg, etc. — resolved in Phase 2/3)
- Each exports `metadata` with `title` and `description` stubs

## Animation Contract

Phase 1 installs the motion library and wires the global config. Full animation variants are Phase 2 (ANIM-03 through ANIM-12). Phase 1 scope:

| Requirement | Contract |
|------------|----------|
| ANIM-01: `motion/react` installed | Install `motion` package (v12+), import from `motion/react` |
| ANIM-02: Global MotionConfig | `<MotionConfig reducedMotion="user">` in `src/components/providers.tsx` (client component) |
| Navigation scroll transition | CSS `transition` only (no motion/react) — `200ms ease` on background and shadow |
| Navigation hamburger open/close | Sheet component animation handled by Radix (built-in) |
| No FOUC on fonts | `next/font` with `adjustFontFallback: true` handles this natively |

All Phase 1 animations: transform + opacity only. No width/height/top/left animation.

## Accessibility Contract

| Requirement | Implementation |
|------------|----------------|
| Skip-to-content | First focusable element in `<body>`; visually hidden until focused; links to `#main-content`; `z-index: 9999` |
| Focus ring | `outline: 2px solid #8442f5; outline-offset: 2px` on all focusable elements — set globally via `@layer base` |
| Minimum touch target | 44×44px for all interactive controls (nav links, buttons, FAB) |
| `<html lang>` | `lang="en-IN"` in `src/app/layout.tsx` |
| Semantic landmarks | `<header>` (Navigation), `<main id="main-content">`, `<footer>` — in root layout |
| Keyboard navigation | All Phase 1 interactive elements (nav, drawer, FAB) reachable and operable via keyboard |
| Screen reader labels | All icon-only buttons have `aria-label`; decorative SVGs have `aria-hidden="true"` |
| Heading hierarchy | Each skeleton page: one `<h1>` only; no heading skips |
